# BIAI AI-Powered CRM

This CRM project transforms how businesses handle customer enquiries by leveraging AI and a user-friendly interface to ensure that no customer goes unanswered and spam/scam messages are handled appropriately.

This single-page application is built with Next.js, FastAPI, and MySQL (using SQLAlchemy ORM). It uses AI to process new enquiries, generate weekly summaries, and load multiple enquiries at once from the `sample_data.py` file.

## Key Feature I Want to Add Next

I want to integrate WhatsApp, Messenger, and websites so businesses can reply to customers with just one click. I believe this is the most important missing feature in the CRM.
